# Частые вопросы

[English](FAQ.md) · [Русский](FAQ.ru.md)

## Разрешён ли Netwick правилами Riot?

Netwick никогда не трогает игру, её файлы и память, античит и API Riot. Он не показывает данные других игроков, не нажимает клавиши и не кликает за вас. Он только читает и меняет настройки Windows и собственные файлы кэша Riot Client — с вашего разрешения. Подробнее: [правила Riot о сторонних приложениях](https://support.riotgames.com/en-us/valorant/account/third-party-applications).

## Безопасно ли нажимать «Сделать за меня»?

Каждый шаг заранее говорит, что изменится, зачем, нужна ли перезагрузка и можно ли это отменить. Пока вы не нажмёте кнопку, ничего не происходит. Если шагу нужны права администратора, Windows спросит разрешение (UAC). Шаги, которых нет в статьях Riot, помечены.

## Что делает каждый сценарий ремонта?

| Сценарий | Что происходит | Перезагрузка | Отмена |
| --- | --- | --- | --- |
| Авто-исправление | Проходит безопасные шаги от простых к сложным, на каждом спрашивает | нет | где возможно |
| Быстрый ремонт | Закрывает Riot, чистит кэш клиента и DNS, перезапускает службу Vanguard | нет | не нужна |
| Полный сброс сети | Кэш, сессия входа, адреса серверов, служба Vanguard, сброс сети Windows | да | нет |
| Узлы и маршруты | Проверяет каждый адрес серверов Riot; по желанию закрепляет рабочий в файле `hosts` | нет | да |
| Служба Bonjour | Останавливает Apple Bonjour, не удаляя | нет | да |
| Переустановка Vanguard | Сначала перезапускает службу, затем показывает штатное удаление Windows | да | — |
| Убрать маршруты | Удаляет адреса Riot из файла `hosts` | нет | да |

## Я нажал «Сбросить сессию входа». Аккаунт потерян?

Нет. Просто войдите заново. Netwick никогда не видит и не хранит ваш пароль.

## Проверка пишет «Проблема у Riot»

Riot сообщает о сбое или технических работах. Локальный ремонт не поможет — подождите и посмотрите [статус серверов Riot](https://status.riotgames.com/).

## Что такое оценка состояния?

100 минус баллы за проблемы последней полной проверки: 22 за красный результат, 9 за жёлтый, 2 за проверку, которую не удалось выполнить. Информационные подсказки оценку не снижают. История и медали хранятся только на вашем компьютере, их можно стереть в настройках.

## Что значат цифры в «Качестве связи»?

Netwick 12 раз подряд открывает соединение с сервером Riot. *Задержка* — среднее время, *джиттер* — насколько оно «прыгает» между измерениями, *потери* — доля неудачных попыток. Меньше 80 мс без потерь — хорошо; высокий джиттер или потери обычно значат проблемы Wi-Fi или загруженный роутер.

## Windows пишет «Windows защитила ваш компьютер»

Netwick пока не подписан сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Файл можно проверить по хешу со страницы релиза, см. [README](../README.ru.md#как-убедиться-что-файл-настоящий).

## Куда сообщить о проблеме?

Создайте issue в репозитории. О проблеме безопасности пишите через приватную форму, см. [SECURITY.md](../SECURITY.md). Не публикуйте отчёт для поддержки, не прочитав его.
