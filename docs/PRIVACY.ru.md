# Приватность

[English](PRIVACY.md) · [Русский](PRIVACY.ru.md)

**Коротко: Netwick ничего о вас никуда не отправляет.** Ни телеметрии, ни аналитики, ни отчётов о сбоях, ни аккаунтов, ни рекламы.

## К чему подключается Netwick

Только когда вы нажимаете кнопку и никогда с вашими личными данными:

| Что | Зачем | Что отправляется |
| --- | --- | --- |
| Публичные серверы Riot (те же адреса, что у Riot Client) | «Проверить компьютер», «Узлы и маршруты» | Один обычный запрос `GET /` на адрес, заголовок `User-Agent: Netwick/<версия>` |
| Публичные DNS 1.1.1.1, 8.8.8.8, 77.88.8.8 | Узнать адреса серверов Riot | Обычный DNS-вопрос про имя сервера Riot |
| Публичный статус серверов Riot (JSON, регион из настроек) | «Статус серверов Riot» | Обычный запрос, ничего о вас |
| Один сервер Riot, порт 443 | Тест «Качество связи» | Только открытие и закрытие соединения, без данных |
| GitHub (только если включена проверка обновлений) | Узнать номер последней версии | Обычный запрос, ничего о вас |

## Что остаётся на вашем компьютере

| Файл | Что внутри |
| --- | --- |
| `%APPDATA%\Netwick\settings.json` | Ваши настройки |
| `%APPDATA%\Netwick\crosshairs.json` | Ваши заметки о прицелах |
| `%LOCALAPPDATA%\Netwick\undo.json` | Что Netwick изменил, чтобы это можно было отменить |
| `%LOCALAPPDATA%\Netwick\profile.json` | История проверок, оценки, счётчики и медали (без имён и адресов) |
| `%ProgramData%\Netwick\backups\` | Резервные копии файла `hosts` (читаются только администраторами) |

Историю и медали можно стереть в любой момент: **Настройки → Очистить историю и медали**.

## Что Netwick читает и меняет

- Читает настройки Windows и файлы установки Riot. Из журналов Riot Client берёт только имена серверов и типы ошибок, строки журнала не копирует.
- Никогда не просит и не хранит логин и пароль от Riot.
- «Очистить кэш клиента» и «Сбросить сессию входа» удаляют файлы Riot Client на этом компьютере только по вашей кнопке. Файлы сессии удаляются, а не копируются.
- Каждое изменение сначала объясняется и подтверждается. Обратимые изменения отменяются одной кнопкой.

## Отчёт для поддержки

Отчёт создаётся, только когда вы его открываете, а копируется или сохраняется только по кнопке. Имя пользователя, имя компьютера, путь к домашней папке, e-mail, токены, Riot ID и IP-адреса (кроме адресов серверов Riot) удаляются автоматически. Прочитайте отчёт перед отправкой.
