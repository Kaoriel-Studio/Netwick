# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting: open the repository → **Security** → **Report a vulnerability**.
Describe what you found, how to reproduce it and which version you used. You will get an answer within 7 days.

Only the latest release is supported with security fixes.
